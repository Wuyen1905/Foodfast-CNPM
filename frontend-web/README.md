# Giao diện FoodFast

Thư mục này chứa giao diện React và TypeScript đang được sử dụng cho khách hàng, nhà hàng, quản trị viên và nhân viên quản lý FoodFast.

## Chạy giao diện

```powershell
npm ci
npm run dev:fast
```

Giao diện mặc định chạy tại `http://localhost:5173` và kết nối API tại `http://localhost:8080/api`.

## Kiểm tra

```powershell
npm run type-check
npm run lint
npm test
npm run build
```

Danh sách tài khoản dùng thử, hướng dẫn MySQL và VNPay được trình bày trong [README chính](../README.md).
